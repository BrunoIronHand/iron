# Modelo Visual — Glide Kip

## 1) Visão Geral Estratégica

```mermaid
flowchart TD
    A[Glide Kip] --> B[Transição: Suspensão -> Apoio Frontal]
    A --> C[Eficiência Biomecânica]
    A --> D[Base para Ligações Avançadas]
    C --> C1[Momento Angular -> Ascensão Vertical]
    C --> C2[Menor Gasto Energético]
    D --> D1[Kip-Cast -> Handstand]
```

---

## 2) Pré-requisitos (Checklist Técnico)

```mermaid
flowchart LR
    P[Pré-requisitos] --> P1[Glide Swing consistente]
    P --> P2[Hollow Body sólido]
    P --> P3[Ombros ativos e braços rígidos]
    P1 --> P1a[Sem arrasto dos pés no solo]
    P2 --> P2a[Core ativo + coluna estável]
    P3 --> P3a[Depressão + protracção escapular]
```

**Regra de ouro:** sem base postural sólida, há perda de energia + aumento de risco de compensações lombares.

---

## 3) Decomposição em 3 Fases

```mermaid
flowchart LR
    F1[Fase I: Glide] --> F2[Fase II: Snap]
    F2 --> F3[Fase III: Stem Rise]

    F1 --> F1d[Impulso inicial forte]
    F1 --> F1e[Pernas estendidas + hollow]

    F2 --> F2d[Fecho explosivo da anca]
    F2 --> F2e[Pés em direção à barra]

    F3 --> F3d[Tração da barra ao longo das pernas]
    F3 --> F3e[Rotação de punhos + bloqueio de cotovelos]
    F3 --> F3f[Final em apoio frontal]
```

### Relação de dependência
- **Glide curto** -> **Snap fraco** -> **Subida comprometida**.
- Fluidez entre fases = conservação da energia cinética até ao apoio.

---

## 4) Diagnóstico Rápido de Erros (Mapa de Correção)

```mermaid
flowchart TB
    E1[Pouco momento no Glide] --> C1[Aumentar impulso inicial + extensão total]
    E2[Core relaxado] --> C2[Reforçar hollow + evitar hiperextensão lombar]
    E3[Snap lento/tardio] --> C3[Fecho explosivo no ápice do deslize]
    E4[Puxada fraca / braços fletidos] --> C4[Tração contínua da barra + braços firmes]
    E5[Punhos sem rotação] --> C5[Rodar punhos no timing pé-barra]
```

> **Ponto crítico:** a rotação dos punhos define a passagem do centro de gravidade para cima da barra.

| Métrica | Escala | Meta semanal |
|---|---:|---:|
| Qualidade do Glide | 0-5 | >= 4 |
| Integridade Hollow | 0-5 | >= 4 |
| Explosividade do Snap | 0-5 | >= 4 |
| Timing da rotação de punhos | 0-5 | >= 4 |

### Critério de progressão
- Avançar para combinações (ex.: kip-cast) apenas quando o atleta mantiver média **>= 4** em todas as métricas por 2 semanas consecutivas.
