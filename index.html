GymPro

Gestão completa de ginástica FIG num único ficheiro. Funciona 100% no browser, guarda dados no localStorage e fica disponível offline após o primeiro acesso.

Aviso: o armazenamento local não está disponível neste modo. Os dados ficarão apenas nesta sessão. Use Backup/Restauro para guardar manualmente.
